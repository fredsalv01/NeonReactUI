🎓 USAGE EXAMPLE
═══════════════════════════════════════════════════════════════════════════

import { Button, Input, Card, useToast } from './ui';

function App() {
  const { show, ToastContainer } = useToast();

  return (
    <>
      <ToastContainer />
      <Card>
        <Input label="Name" />
        <Button onClick={() => show('Saved!', 'success')}>
          Save
        </Button>
      </Card>
    </>
  );
}

❓ COMMON QUESTIONS
═══════════════════════════════════════════════════════════════════════════

Q: Do I need npm install?
A: Yes, run 'npm install' to download all dependencies.

Q: Can I modify components?
A: Yes! All components accept 'className' prop for customization.

Q: How do I change colors?
A: Edit 'tailwind.config.js' to modify the color palette.

Q: Can I deploy this?
A: Yes! Run 'npm run build' and deploy the 'dist' folder.

Q: Is this mobile responsive?
A: Yes! All components work on all screen sizes.

Q: Do I need to customize the components?
A: No, they work out of the box. Customize as needed.

🐛 IF SOMETHING GOES WRONG
═══════════════════════════════════════════════════════════════════════════

Styles not showing?
  → Restart dev server: npm run dev
  → Clear browser cache (Ctrl+Shift+Delete)

Import errors?
  → Check file names (case-sensitive)
  → Verify imports from './ui'

Dev server won't start?
  → Delete node_modules folder
  → Run: npm install again
  → Run: npm run dev

Can't find components?
  → Check COMPONENTS.md for proper imports
  → Use: import { Button } from './ui'
